# 대도서관 · 연결되는 지식

논문과 독립적으로 작성한 한국어 해설, 임상 질문을 함께 읽는 공개 지식 자료실입니다.

## 첫 공개판 범위

- AON 공개 색인 293건과 임상 자료 목록 78건을 연결하고 서지가 일치한 7건을 병합한 **364개 서지 항목**.
- **13개 읽기 안내·주제별 해설**, 자료 검색·필터·원출처 연결.
- 철학·경제·사회는 검토된 자료를 추가할 준비 단계입니다.

364는 독립 임상시험 수나 고유 논문의 확정 수가 아닙니다. 각 자료의 검토 범위를 확인하세요. 전체 전문·부록을 새로 재검증한 자료실이나 개인별 진단·치료 서비스가 아닙니다.
